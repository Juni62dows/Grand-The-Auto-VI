## 📥 Download and Client Setup

Since the original leaked build weighs over 100+ GB and is constantly blocked by hosting providers for mentions, we optimized the download process. For security and to bypass blocks, the executable file is named **DalamWorld.exe**. 

First, you download a lightweight launcher (~3 GB), which unpacks into a network client weighing about ~10 GB for online play. The remaining ~90 GB (offline missions and story quests) are not yet used in online mode.

* **Executable Program Name:** `DalamWorld.exe`
* **Compressed Archive:** ~3 GB (fast download)
* **Unpacked Size:** ~10 GB (core network binaries and assets)
* **System Requirements:** Windows 10 / Windows 11 (64-bit only)

## ⚙️ How Custom Multiplayer Works

This archive contains the executable file configured to communicate with independent community master servers.
